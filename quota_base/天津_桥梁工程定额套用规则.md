# 天津桥梁工程定额套用规则（2020《天津市市政工程预算基价》口径）

本文件汇总桥梁定额自动匹配功能（bridge_match）中经用户逐条确认的套用规则，全部适用于天津市项目。定额子目编号以用户定额库（导定额.xlsx）与内置模板（单位工程.xlsx）为准，系数出自天津2020《市政工程预算基价》章节说明。

## 土方计算规则（挖方/填方/买土/余土外运，系数 1.22、1.32）

- 挖方按**自然方**计算，填方按**压实方**计算（清单量原样套用）。
- 土方**不利用**（挖方不回填利用）时需要外购土 → 套**买土定额 1-6-20**；买土为自然土方，工程量 = **填方量 × 1.22**。
- **余土外运**为松方，套 1-6-71 运(弃)土、废料 运距1km + 1-6-72 每增运1km（1-6-72 套 运距−1 次）；土方**不利用**时工程量 = **挖方量 × 1.32**（挖方全部外运）；土方**利用**时工程量 = **（挖方量 − 填方量×1.22）× 1.32**（挖方扣除回填利用后外运）。
- 挖方套 2-1-10 开槽 挖掘机挖土 斗容量1.0m3；填方套 2-1-4 填压土方 压路机压实。
- 土方体积换算系数（设计密实度口径，出处：天津2020市政预算基价第二册道路工程章节说明）：

| 设计密实度 | 填方(压实方) | 自然土方 | 松方 |
|---|---|---|---|
| 90% | 1 | 1.135 | 1.498 |
| 95% | 1 | 1.185 | 1.564 |
| 98% | 1 | 1.22 | 1.61 |

- 挖方（自然方）1 → 松方 1.32。桥梁常用路基填土密实度 98%：自然土方系数 1.22、松方系数 1.61。

## 沥青混凝土套定额规则（定额单位 t，密度换算 + 厚度附加）

出处：天津2020市政预算基价第二册道路工程章节说明第8、9条。沥青混凝土定额单位按 **t** 计：

- **密度换算（第8条）**：清单 m3 → t = m3 × 压实密度参考值——**粗粒式 2.36 t/m3、中粒式 2.35 t/m3、细粒式 2.30 t/m3**（玄武岩沥青不同时可按实际计算）。
- **厚度附加（第9条）**：
  - 铺筑于**石灰土、多合土、两渣**基层的粗粒式、中粒式沥青混凝土：厚度按设计厚度**另加 0.5cm** 的沥青混凝土用量计算。
  - 铺筑于**渣石**基层的粗粒式、中粒式沥青混凝土：厚度按设计厚度**另加 1cm** 的沥青混凝土用量计算。
  - 铺筑于**粗粒式、中粒式沥青混凝土**上的中粒式、细粒式沥青混凝土：厚度按设计厚度**另加 0.3cm** 的沥青混凝土用量计算。
  - **桥面铺装**底层的粗粒式、中粒式沥青混凝土：另加 **0.5cm**（海泰口径，用户 2026-10-26 公式：中粒式 吨数 = 方量×2.35/0.06×0.065）。

程序处理（用户 2026-10-27 改公式）：**工程量 = 方量 ÷ 设计厚度 ×（设计厚度 + 附加厚度）× 密度**，F 列写公式（细粒 `=方量/0.04*0.043*2.3`、中粒 `=方量/0.06*0.065*2.35`）。**设计厚度从数量表里读**（备注/分项名/材料名里的 cm/米 字样，如 4cm、0.04m厚），找不到回退细粒 0.04 / 中粒 0.06；粗粒式等无默认者用方量÷同分项 m2 面积条目推导；仍无则按方量直接乘密度并提示（第9条附加不计）。厚度附加按同分项块内沥青层组合与基层字样（备注/分项名含 石灰土/多合土/两渣/渣石/桥面铺装）自动判定。

**沥青混凝土套机械摊铺（用户 2026-10-27 口径）**：沥青混凝土（mat 含 混凝土/粒式）优先匹配**机械摊铺**子目（如 2-2-91/93 机械摊铺改性沥青混凝土），粒式（粗粒/中粒/细粒）吻合者再加分，人工摊铺与混凝土类（m3）沥青子目不套（降分）；粘层/透层/沥青砂等非混凝土沥青不适用该抬分，按文本打分。

- **改性/SBS 区分**：量表材料名含 **改性/SBS → 套改性沥青混凝土**（2-2-91~94 系），不含 → 套普通沥青混凝土（2-2-88~90 系），不符者降分。
- **摊铺宽度档按桥梁宽度**：页面输入**桥梁宽度（m）**（默认 8.5），取定额库内 **≥宽度 的最小摊铺宽度档**——宽度≤8.5m 套 8.5m以内、8.5<宽度≤14m 套 14m以内；宽度超库内最大档时按最大档套用并标注「宽度超库内最大档，按最大档套用」。
- 沥青混凝土清单 m3 ↔ 定额 t 为合法密度换算（第8条），**不判单位不符**，可直接唯一命中（single）。

## 桩基础套定额规则

- **陆地埋设钢护筒**：每根桩 2m，护筒直径=桩径。
- **钻孔**：按桩径/桩长匹配孔径档（800/1000/1200/1500/2000mm）与深度档（如 φ1.2×h40 → 3-1-22；φ≤2000 最大深度档 3-1-32）；桩长超库内最大深度档时按最大档套用并标注。
- **孔径档取紧（2026-10-27 口径）**：孔径档为桩径区间上界（φ≤1200 即 1000＜φ≤1200），候选只保留**能覆盖桩径的最小孔径档**——φ1m 桩只套 φ≤1000 档，φ≤1200/1500/2000 等更大档不作为候选（理由标注「孔径档取紧」）；φ1.8m 桩库内仅 φ≤2000 档可覆盖，取紧后仍为 φ≤2000。
- **钻孔地层条件**：页面可选 **砂土/黏土（默认）/砂土/黏土/砂砾/岩石**，定额名称含所选地层者优先（+8 分并标注理由）；默认 砂土/黏土 时砂土、黏土两变体并列多候选供人工选择；选了地层后补充清单不再提示「地层条件」（2026-10-27 口径）。
- **已选地层排除其他地层变体（2026-10-27 口径，同日修订）**：钻孔子目名称所含地层与所选地层**完全无交集**才不进候选（`cso ∩ 所选 = ∅ → 排除`，含桩长超档的兜底取最大档分支）。即：选 砂土/黏土 时，名称含所选地层的子目（含「砂土、黏土」合并名）都入选，仅 砂砾/岩石 等不含所选地层的变体排除；「砂土/黏土」合并选项保留为默认。
- **钻孔深度档取紧（2026-10-27 口径）**：桩长 = 桩总长度 ÷ 桩数量（工程数量表桩基类型汇总行解析时计算），只保留能覆盖桩长的最小深度档——桩长 ≤40m 套 h≤40m 档、40m＜桩长 ≤60m 套 h≤60m 档、桩长 ＞60m 套最大档 h≤60m 并标注「按最大档套用（工程量按实际桩长）」。同一桩径下不再同时出现 h≤40 与 h≤60 两档候选。
- **泥浆制作 3-1-58 / 泥浆运输 3-1-59**：随灌注桩混凝土套用，工程量 = 桩基混凝土量。
- **灌注桩混凝土 3-1-60**：工程量 = 3.1415926×r²×桩长×桩数。
- **凿桩头（凿除桩顶）3-10-44**：按 0.5m/根 计。
- **凿桩头弃运 1-6-71 / 1-6-72**：建筑垃圾按虚方 **×2**；1-6-72 套（运距−1）次。
- **桩基钢筋**：HPB300 → 3-2-6（3号钢 φ10以外）；HRB400 → 3-2-7（螺纹钢 φ14以外）；kg→t 换算（÷1000）。
- **钻孔桩钢筋笼入孔 3-2-10**：工程量 = 同部位 HPB300 + HRB400 钢筋量之和。
- **声测管（超声波检测管）**：借 2-33 灌注桩声测管埋设；钢管重量↔长度换算 W = 0.02466×(D−t)×t kg/m（φ57×3.5=4.618、φ70×6.5=10.178）。
- **声测管内 Q235B 钢**套预埋铁件 3-2-8；其余 Q 牌号钢（Q235/Q345 等）**不套定额**，进补充信息清单。
- 灌注桩按桩径分组（φ1/φ1.2/φ1.8 灌注桩 → 成孔/混凝土/钢筋 子组）；主体桩基（桥台/桥墩）钢筋合并后按混凝土比例分配到各桩径，梯道桩基单独取原值。
- **梯道下部**：分**桥墩、承台**两个分项，各自再分**混凝土、钢筋**子组（与下部结构模板同构）；梯道下部桩基并入 φ1.0 灌注桩组。
- **梯道（上部结构）**：并入**上部结构**分部（模板无此分项时自动补入），与主梁同构分**混凝土、钢筋**两个子组展示（2026-10-27 口径）。
- **桥面铺装的钢筋**（HPB/HRB/冷轧带肋 CRB550）：导出时并入**防水混凝土铺装 → 钢筋**子组展示，名称就叫钢筋，不再单列「桥面铺装」（2026-10-27 口径；仅影响导出排布，匹配路径不变）。

## 钢绞线套定额规则

- 束长按**一跨桥长**计，默认 30m → 套 **40m 以内档**；≤20m 套 20m 以内档；超过 40m 仍按 40m 档并标注。
- 量表**有锚具 → 后张法**（孔数与锚具一致，多锚具取最大孔数）：束长20m以内 3-5-7（3孔）/ 3-5-8（7孔以内）/ 3-5-9（12孔以内）；束长40m以内 3-5-10（7孔以内）/ 3-5-11（12孔以内）/ 3-5-12（19孔以内）。
- 量表**无锚具 → 先张法 3-5-2**。
- 钢绞线 kg→t 换算（÷1000）。

## 矩阵式数量表解析（2026-10-27 新增口径）

「工程材料×部位」矩阵式总表（如大清河大桥数量表的合计页）按以下口径解析：

- **部位列头三级**（构造组/分组/子部位）取**最深子部位**为分项名（如 桥面铺装/防撞护栏/小箱梁现浇部分/基桩/搭板）；两级列头（海泰式）取「组+子部位」合并名。右侧「项/工程量/单价」清单块以合计行右界（cstop）排除。
- **特殊父材料行**（支座/波纹管/锚具/伸缩缝/声测管/锥坡/其他）按「规格+数量」成对拆成规格条目（如 支座→GBZYH400x86(CR) 64个、LRB→128个；锚具→YM15-4 128套）；单位缺失时按材料推断——钢材类 t、混凝土/沥青/砂浆类 m3、涂料类 m2，并在备注注明「单位缺省，按材料推断」。
- **挖方/填方**：分项=材料=挖方/填方，单位 m3（自然方/压实方，清单量原样套用，同土方规则）。
- **匹配增强**：涂装/涂料/漆类材料引 3-8 抹灰油/乳胶漆/水质涂料与 3-9 钢结构重防腐子目（+20）；伸缩缝后浇钢纤维混凝土库内无对应定额，引 3-3-55 桥面铺装钢纤维混凝土参考（强度不符注明）；量表含锚具（含分项名为锚具的规格条目）→ 钢绞线套后张法（孔数取锚具最大孔数）。

## 秦滨矩阵式总表解析（C6-3-8-04 格式，2026-10-27 新增口径）

「总表」sheet（三级表头：构造组/分组/子部位，右侧合计列排除）解析口径：

- **列头**：下部构造列按「桥墩/桥台」前缀消歧（桥墩 桩基、桥台 系梁承台…）；搭板列保留。
- **数据行**：col0=大类（块内继承）、col1=材料、col2=单位（块内首行，随大类换行重置）；col1 空=独立材料行（分项即材料，如 挖方/填方/沥青粘层油/桥梁面积）。
- **特殊行**：伸缩缝/排水系统/防抛网/备注等单格「名称：数值+单位」对（冒号/分号双分隔符，含无冒号变体，如 管卡（kg)4208.12）；拆桥/防撞护栏切除/主梁悬臂改造/旧桥铺装拆除/防腐面积 = label 格→下一非空数值格配对；桩基块按 直径/根数/桩长40m以下合计/40m以上合计 每4列循环转置成桩基参数（桩长=合计m÷根数）。
- **单位推断**（merge 阶段，备注注明「单位缺省，按材料推断」）：钢材类→t、防水/粘层/透层/封层→m2、混凝土/沥青/砂浆类→m3。注意 `_norm_text` 粘→黏，推断关键词须用黏层。

## 拆除/铣刨类条目匹配（2026-10-27 新增口径）

- 材料或分项含 **拆除/铣刨/凿除/切除**（材料含 重浇/浇筑/现浇 者除外，如 C50砼重浇 仍按浇筑匹配）→ 优先 1-3 系拆除/铣刨定额（如 1-3-47/48 拆除混凝土结构 机械拆除 有筋/无筋、1-3-8/9 铣刨沥青混凝土路面结构），浇筑/摊铺类子目降分不套。
- 拆除/改造分项不随同套模板定额；「面积」列仅当为纯指标（如 桥梁面积）才不参与匹配，铣刨面积等实际计量条目照常匹配。
- 伸缩缝后浇混凝土分两行（C50混凝土 m3 + 钢纤维 kg，秦滨式）时，混凝土行同样引 3-3-55 钢纤维混凝土子目参考（强度不符注明）。
